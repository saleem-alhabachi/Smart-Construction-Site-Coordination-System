# Demo Plan

## Demo Objective
The demo should show that the Smart Construction Site Coordination System provides a working MVP for managing tasks, reporting risks, and generating project progress summaries.

## Demo Flow

1. Open the GitHub repository and briefly show the project structure.
2. Show the CI workflow configuration in `.github/workflows/ci.yml`.
3. Run the MVP locally with `npm start`.
4. Explain the user roles: Project Manager, Site Engineer, and Subcontractor/Foreman.
5. Show sample tasks, reported risks, and the generated weekly report from the console output.
6. Show the sprint board link and explain how work was organized.
7. Show the risk analysis and testing plan documentation.

## Demo Checklist

- Repository is up to date
- CI workflow file is present
- MVP runs successfully with `npm start`
- Tests pass with `npm test`
- Sprint board link is added
- Documentation files are accessible from the repository

## Expected Demo Artifacts

- Working MVP source code
- GitHub repository
- CI/CD pipeline configuration
- Sprint board reference
- Risk documentation
- Testing and validation plan
