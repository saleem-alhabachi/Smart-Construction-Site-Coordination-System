## Sprint Structure

### Sprint 1 - Foundation (Completed)
- Project planning and documentation
- Core class design (User, Task, Risk models)
- Node.js MVP implementation
- Basic CI workflow setup
- Risk analysis and testing plan

### Sprint 2 - Production Architecture (Completed)
- Migrate to Python/FastAPI backend
- PostgreSQL database with SQLAlchemy ORM
- JWT authentication and role-based access control
- Docker containerization
- Alembic database migrations

### Sprint 3 - Features and AI (Completed)
- Task CRUD API with Kanban status workflow
- Risk CRUD API with severity tracking
- Dashboard KPI endpoint
- Weekly report generation
- Ollama AI integration (analysis + chat)
- User management endpoints

### Sprint 4 - Frontend and Deployment (Completed)
- Web GUI (dark-mode SPA)
- Login/Register interface
- Dashboard with KPI cards and charts
- Kanban task board
- Risk tracker table
- AI Assistant chat and analysis panel
- Nginx reverse proxy with HTTPS
- Docker Compose full stack orchestration
- CI/CD pipeline with VPS auto-deploy
- Documentation updates

## Workflow Stages

| Stage | Description |
|-------|-------------|
| Backlog | Items identified but not yet planned |
| To Do | Items planned for current sprint |
| In Progress | Work actively being done |
| Review | Code review or testing |
| Done | Completed and verified |
