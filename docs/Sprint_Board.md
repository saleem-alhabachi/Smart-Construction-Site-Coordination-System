# Sprint Board

Project work is tracked in Jira using a sprint board that organizes tasks into the following workflow stages:

- To Do
- In Progress
- Review
- Done

The board is used to assign responsibility, monitor weekly progress, and review blocked tasks during project meetings.

## Suggested Board Structure

| Sprint | Focus |
| --- | --- |
| Sprint 1 | Planning, requirements, Jira setup, project overview |
| Sprint 2 | System design, UML, database and architecture decisions |
| Sprint 3 | Task and schedule management implementation |
| Sprint 4 | Risk management and reporting workflows |
| Sprint 5 | Testing, bug fixing, CI checks, and documentation updates |
